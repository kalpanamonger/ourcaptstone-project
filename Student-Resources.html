2. Understanding Binary Place Values

In binary, each position represents a power of 2. Starting from the right, the place values are 1, 2, 4, 8, 16 and so on.

Binary digit 1 0 1 1
Place value 8 4 2 1
Calculation 8 0 2 1

Example: 1011₂ = 8 + 0 + 2 + 1 = 11₁₀.

3. Worked Example: Convert Binary to Decimal

Convert 1101₂ into decimal.

  1. Write the place values: 8, 4, 2, 1.
  2. Multiply each binary digit by its place value.
  3. Add the results: (1 × 8) + (1 × 4) + (0 × 2) + (1 × 1).
  4. The total is 8 + 4 + 0 + 1 = 13.

Answer: 1101₂ = 13₁₀.
