Data Representation and Number System

🎯 Learning Objectives

By the end of this lesson, students should be able to:

  • Define data representation and number system.
  • Explain why computers use binary numbers.
  • Identify decimal, binary, octal and hexadecimal number systems.
  • State the base and symbols used in each number system.

1 What Is Data Representation?

Data representation is the way information is expressed, stored and processed in a computer.

Computers work with different types of information, such as:

📝 Text Letters, words and sentences.
🔢 Numbers Quantities and calculations.
🖼️ Images Photographs and drawings.
🎵 Audio Recorded voices and music.
🎬 Video Moving pictures.

Although these types of information look different to us, computers represent them internally using binary digits, called bits.

Example: A student types their name

SONAM

01010011 01001111
01001110 01000001 01001101

Text is represented using digital codes.

Remember: When a student types their name on a computer, the computer represents the text using digital codes made up of binary digits. The binary sequence shown above is illustrative; actual text encoding depends on the character encoding.

2 What Is a Number System?

A number system is a method of representing numbers using a set of symbols and rules.

There are four important number systems in this lesson.

Number System Base Symbols Used Example
Decimal 10 0–9 245
Binary 2 0 and 1 1011₂
Octal 8 0–7 57₈
Hexadecimal 16 0–9 and A–F 2F₁₆
Decimal Base 10 Digits 0–9
Binary Base 2 Digits 0, 1
Octal Base 8 Digits 0–7
Hexadecimal Base 16 Digits 0–9, A–F
Did you know? Each octal digit can represent three binary bits, and each hexadecimal digit can represent four binary bits.

3 Understanding Place Value

In a positional number system, the value of a digit depends on its position.

Decimal Example: 352

352 = (3 × 100) + (5 × 10) + (2 × 1)

The place values are powers of 10:

10², 10¹, 10⁰

300 + 50 + 2 = 352

Binary Example: 1011₂

1011₂ = (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1)
1011₂ = 11₁₀

The place values are powers of 2:

2³, 2², 2¹, 2⁰
What is a subscript? The small number written below a number, such as the 2 in 1011₂, identifies the base of that number system. It is called a subscript.

4 Why Do Computers Use Binary?

Computers use electronic circuits that can represent two states, such as ON and OFF. These states can be represented using binary digits.

1 ON

A state represented by binary 1.

0 OFF

A state represented by binary 0.

💡 Bit

A single binary digit is called a bit.

0 or 1 = 1 bit

💻 Byte

A group of eight bits is called a byte.

10101010 = 8 bits
