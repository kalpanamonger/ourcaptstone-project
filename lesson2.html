CLASS IX · LESSON 02

Binary Number System to Other Number Systems

Learn how to convert binary numbers into decimal, octal and hexadecimal using simple steps, tables and practice.

Start Learning ↓

1. Learning Objectives

By the end of this lesson, you should be able to:

  • Convert binary numbers into decimal numbers.
  • Convert binary numbers into octal numbers.
  • Convert binary numbers into hexadecimal numbers.

2. What Is the Binary Number System?

The binary number system has a base of 2. It uses only two digits: 0 and 1. Each binary digit is called a bit.

Binary number 1 1010₂
Binary number 2 1101₂
Binary number 3 10011₂
Remember: digits 2–9 cannot be used in a binary number because binary uses only 0 and 1.

3. Binary to Decimal Conversion

To convert a binary number to decimal:

  1. Start from the right-hand side.
  2. Write place values as powers of 2, beginning with 2⁰.
  3. Multiply each binary digit by its place value.
  4. Add the results.

Visualising the place values

The place values from right to left are powers of 2: 2⁰ = 1, 2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16, and so on.

4. Binary to Octal Conversion

To convert binary to octal:

  1. Start grouping binary digits from the right.
  2. Make groups of three bits.
  3. Add leading zeros on the left if necessary.
  4. Convert each group into an octal digit.

5. Binary to Hexadecimal Conversion

To convert binary to hexadecimal:

  1. Group binary digits into sets of four, starting from the right.
  2. Add leading zeros on the left if needed.
  3. Convert each group into a hexadecimal digit.

8. Lesson Summary

  • Binary uses only 0 and 1.
  • For binary-to-decimal conversion, multiply each digit by its power-of-2 place value and add the results.
  • For binary-to-octal conversion, group bits in threes from the right.
  • For binary-to-hexadecimal conversion, group bits in fours from the right.
  • Add leading zeros to the left when needed to complete a group.
