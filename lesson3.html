CLASS IX · DIGITAL TECHNOLOGY AND INNOVATION

Lesson 3: Octal Number System to Other Number Systems

Learn how to convert octal numbers into binary, decimal and hexadecimal.

1. Learning Objectives

By the end of this lesson, students should be able to:

  • Explain the octal number system.
  • Convert octal numbers to binary.
  • Convert octal numbers to decimal.
  • Convert octal numbers to hexadecimal.

2. What Is the Octal Number System?

The octal number system is a number system with a base of 8. It uses eight digits, from 0 to 7.

Base = 8 Digits = 0, 1, 2, 3, 4, 5, 6, 7

Examples of octal numbers:

25₈, 147₈ and 706₈
Remember: The digits 8 and 9 are not allowed in the octal number system because its base is 8.

3. Converting Octal to Binary

To convert octal to binary, replace each octal digit with its equivalent three-bit binary number.

Worked Example: Convert 57₈ to Binary

Step 1: Convert each octal digit separately.

5₈ = 101₂

7₈ = 111₂

Step 2: Join the binary groups.

57₈ = 101111₂

Each octal digit becomes exactly three binary bits. You can remove leading zeros from the final binary number.

4. Converting Octal to Decimal

To convert octal to decimal, multiply each digit by its place value. The place values are powers of 8, starting from 8⁰ on the right.

  1. Start with the rightmost digit.
  2. Assign place values 8⁰, 8¹, 8² and so on.
  3. Multiply each digit by its place value.
  4. Add all the results.

Worked Example: Convert 157₈ to Decimal

157₈ = (1 × 8²) + (5 × 8¹) + (7 × 8⁰)

= (1 × 64) + (5 × 8) + (7 × 1)

= 64 + 40 + 7

157₈ = 111₁₀

5. Converting Octal to Hexadecimal

To convert octal to hexadecimal, first convert the octal number to binary. Then group the binary digits into groups of four, starting from the right. Add leading zeros if needed.

Worked Example: Convert 725₈ to Hexadecimal

Step 1: Convert octal to binary.

7 = 111, 2 = 010, 5 = 101

725₈ = 111010101₂

Step 2: Group the binary digits into fours.

0001 | 1101 | 0101

Step 3: Convert each group to hexadecimal.

0001 = 1, 1101 = D, 0101 = 5

Final answer: 725₈ = 1D5₁₆

8. Lesson Summary

  • The octal number system has base 8 and uses digits 0–7.
  • To convert octal to binary, replace each digit with three bits.
  • To convert octal to decimal, use powers of 8 and add the results.
  • To convert octal to hexadecimal, convert to binary and group the bits in fours.
Remember: Practise the conversion steps carefully. Always check that an octal number contains only digits from 0 to 7.
